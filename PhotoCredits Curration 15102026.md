Technical Quality (The Science)

Technical quality measures the raw data, sharpness, and exposure of the uploaded file.
• Sharpness and Focus: The main subject must be crisp and in sharp focus, especially around the eyes in portraits. 
Blurry subjects or motion blur usually lower the quality unless used as a deliberate effect.
• Resolution and Pixel Size: Higher resolutions provide more detail. 
Common standards include Full HD (1080p) or 4K (2160p) for videos, and specific pixel dimensions.

#### Exposure and Dynamic Range: •Member must Check that the image is neither too dark (underexposed/crushed shadows) nor too bright (overexposed/blown-out highlights). 
• Color and Contrast: Colors should look natural or intentionally graded, free from weird color casts, heavy digital noise, or compression artifacts.
• Frame Rate and Bitrate (Videos): Smooth motion relies on standard frame rates like 30 fps or 60 fps. 
Higher bitrates (such as 10–30 Mbps for social media or higher for professional work) retain more visual data without pixelation.

2. Artistic and Compositional Quality (The Art)

Technical perfection does not always mean a great image. 
Artistic evaluation focuses on how the viewers experiences the media:
• Composition: Framing must guide the eye naturally to the subject.
Effective use of rules (like the rule of thirds) and the removal of distracting background elements matter.
• Lighting Quality: Is the light flattering, dramatic, or setting the right mood? 
Good lighting defines shapes and separates the subject from the background.
• Eye-Tracking Flow: A strong visual piece pulls the viewer's gaze directly to the focal point and keeps it inside the frame rather than letting it drift away.

3. How to Perform a Rating Process

• The Culling Pass: Quickly drop out-of-focus shots, accidental blur, or severe exposure errors first.
• Automated & AI Tools: Platforms like Every pixel Labs or Pixlane AI Image Quality Score use technical and aesthetic algorithms to output a numerical score (often 0–100).
• Subjective / Mean Opinion Score (MOS): For video, groups of viewers score the material on a 1-to-5 scale to find a human-perceived average.
• The Rest Test: Put the photo or video away for a day or flip/rotate it horizontally to spot hidden flaws that your brain initially glossed over


Temporal Data (Time-Based)
	•	Date & Time Digitized / Captured: Timestamp. The exact moment the media was taken. Used for chronological sorting.
	•	Date Modified: Timestamp. When the file or metadata was last edited.
	•	Import / Upload Date: Timestamp. When the file was added to the library.

📍 Spatial Data (Location-Based)
	•	GPS Coordinates: Float / Decimal (Latitude and Longitude pairs).
	•	Location Names: String / Text. Reverse-geocoded data like Country, State, City, or Point of Interest (e.g., "Eiffel Tower").

🖼️ Media Attributes & Technical Metadata
	•	Media Type: Enum / Category. Differentiates between Photo, Video, Live Photo, GIF, or Screenshot.
	•	File Extension / Format: String / Category. (e.g., JPEG, PNG, HEIC, MP4, RAW).
	•	Dimensions & Resolution: Integer. Width and Height in pixels, or total Megapixels.
	•	Aspect Ratio: String / Ratio. (e.g., 16:9, 4:3, 1:1).
	•	File Size: Integer / Long. Size in bytes, kilobytes, or megabytes.
	•	Duration: Float / Time. (Videos only) Length of the clip in seconds/milliseconds.
	•	Frame Rate: Integer. (Videos only) Frames per second (e.g., 24fps, 60fps).

🏷️ Content & AI-Generated Data
	•	Keywords / Tags: Array of Strings. User-defined or AI-generated labels (e.g., ["beach", "sunset", "vacation"]).
	•	Detected Objects / Scenes: Array of Strings. AI classifications (e.g., "dog", "car", "mountain").
	•	People / Faces: Array of Object IDs. Groupings of recognized individuals linked to a contact name.
	•	Text in Photo (OCR): String / Text. Words extracted from within the image or document scan.

👤 User Organization & Interaction
	•	Favorite / Star Status: Boolean. (True/False) Used to quickly filter liked media.
	•	Album / Folder Assignment: Array of UUIDs / Strings. Unique identifiers of the collections the media belongs to.
	•	Hidden / Archived Status: Boolean. Dictates visibility in the main grid view.
	•	Trash / Deleted Status: Boolean. Tracks if the item is pending permanent deletion.
	•	Rating: Integer. (Typically 1 to 5 stars) Used in professional workflows like Lightroom.
	•	Description / Caption: String / Text. Custom text notes added by the user.

📷 Camera & Lens Metadata (EXIF data)
	•	Camera Make & Model: String. (e.g., Apple iPhone 15, Sony Alpha 7 IV).
	•	Lens Model: String. The specific lens used.
	•	Aperture: Float. (e.g., f/1.8, f/2.8).
	•	Shutter Speed: String / Float. (e.g., 1/250).
	•	ISO Speed: Integer. (e.g., 100, 800, 3200).
	•	Focal Length: Integer / Float. (e.g., 24mm, 50mm).

2. By Age & Demographic Division

• Little Miss / Pre-Teen / Teen: Focused on youth development, poise, and age-appropriate presentation.
• Miss: Typically for young adult women (unmarried or meeting specific system rules).
• Ms. / Mrs.: For mature, married, or accomplished women balancing career, family, or advocacy.
• Mister: Male equivalents, which may overlap with fitness or modeling showcases.
