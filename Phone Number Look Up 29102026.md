Open-Source Libraries (SDKs)

• Google libphonenumber:
	• Type: Free and open-source library (self-hosted).
	• Languages: Java, JavaScript, Python, C++, and more.
	• Capabilities: Parses, formats (E.164 standard), and validates whether a number is structurally possible and valid for a given country. Does not require an external paid API for basic syntax and format checks.
• NumValidate:
	• Type: Open-source REST API wrapper built on top of Google Libphonenumber.
	• Hosting: Available on GitHub for self-hosting; offers free tier limits (up to 100–1,000 daily requests).
• PhoneInfoga:
	• Type: Open-source phone number OSINT and reconnaissance framework.
	• Capabilities: Gathers carrier information, country of origin, and line type using public sources without requiring an API key (optional paid keys can expand features).

Free-Tier APIs (Freemium)

• Numverify API:
	• Type: REST JSON API for global validation.
	• Free Tier: Includes 250 free validation requests per month (no credit card required).
	• Capabilities: International number validation, location data, carrier detection, and line type detection across 232 countries.
• apiphonenumber:
	• Type: Free international phone number validation API.
	• Free Tier: Processes up to 450 phone numbers per month for free.
	• Capabilities: Converts local formats into E.164 standard; provides an SDK and CLI.
