# FingerMobile Protocol - Lush Pressies Application

Welcome to the FingerMobile Protocol's Lush Pressies application - a revolutionary dating platform featuring advanced privacy controls, sophisticated matching algorithms, and innovative features designed to connect users meaningfully.

## 🚀 Overview

Lush Pressies is a cutting-edge dating application that combines a professional LinkedIn-style 3-column layout with advanced privacy features, including:

- **User Privacy Settings**: Granular control over personal information visibility
- **Private PIN Exchange**: Secure method for authenticating private content access
- **EscrowLapidaire Gifting**: Safe and secure gifting system with escrow protection
- **Sovereign Member Privacy**: Advanced privacy controls allowing users to manage their digital footprint
- **Incognito Engine**: Sophisticated anonymity features for enhanced privacy
- **Color Profile Customization**: Personalized visual themes for user profiles
- **Geolocation Services**: Smart matching based on location preferences
- **Gamification Elements**: Engagement through achievements and rewards
- **Real-time Chat**: Seamless communication with typing indicators and read receipts
- **Swipe Interface**: Intuitive card-based matching experience
- **Video/Audio Calls**: Integrated communication features

## 🏗️ Architecture

The application follows a modern microservices architecture:

### Frontend (React/TypeScript)
- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **UI Components**: Headless UI and Heroicons
- **Real-time Communication**: Socket.io Client
- **State Management**: React Context and Custom Hooks
- **Data Visualization**: Recharts

### Backend (Node.js/Express)
- **Framework**: Node.js with Express
- **Database**: PostgreSQL with PostGIS for geospatial queries
- **Caching**: Redis
- **Real-time Communication**: Socket.io
- **Authentication**: JWT Tokens
- **Payments**: Stripe Integration
- **File Storage**: AWS S3
- **Push Notifications**: Firebase Admin

## 🛠️ Getting Started

### Prerequisites
- Node.js (v16 or higher)
- PostgreSQL (with PostGIS extension)
- Redis
- Stripe account (for payments)
- AWS account (for file storage)
- Firebase project (for push notifications)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/fingermobile-protocol/lush-pressies.git
cd lush-pressies
```

2. Install frontend dependencies:
```bash
cd apps/frontend-main
npm install
```

3. Install backend dependencies:
```bash
cd ../backend-api
npm install
```

4. Set up environment variables for both applications (see individual READMEs)

5. Start the backend:
```bash
cd apps/backend-api
npm run dev
```

6. In a new terminal, start the frontend:
```bash
cd apps/frontend-main
npm start
```
